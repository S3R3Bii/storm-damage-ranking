# Fixed comparison: reported storm-damage rankings under missingness and tail stress

29 October 2026. This specific protocol precedes full data retrieval, damage summaries, thresholds, ranks and resampling. Discovery read only official metadata/file listings, source rights and prior research. No event outcomes have been computed. It narrows the original program's broad risk-ranking question to recorded property-damage rankings and explicitly assumed reporting scenarios.

## Decision, population and estimand

For an analyst choosing where to investigate storm-damage records, test whether the ordering of six neighboring states is stable to blank-damage assumptions, extreme-report influence and the resampling unit. This is an evidence-screening study, not a map of true risk, expected insured loss, loss per exposed asset, climate attribution or a financial recommendation.

Fix states ILLINOIS, INDIANA, MICHIGAN, MINNESOTA, OHIO and WISCONSIN. Fix five county-designated event types: Flash Flood, Flood, Hail, Thunderstorm Wind and Tornado. Retain only CZ_TYPE=C. Fix 2015–2019 as calibration and 2020–2023 as evaluation. Selection is convenient; no claim covers all hazards or all United States. Event IDs identify source report/segment units, not necessarily independent physical storms. Episode IDs group NWS entries and need not join an entire meteorological disaster across forecast offices.

The primary score is each state's mean of its four annual shares of property damage within these six states and five types. Each year receives equal weight. This avoids implicitly weighting a year by its national price level or total recorded losses; it does not adjust local asset exposure, vulnerability, construction prices or reporting differences. Also retain nominal cumulative event-year dollars, all state/year/type totals, missing/explicit-zero/positive counts and every annual rank. No dollar amount is described as inflation-adjusted or a causal loss.

## Prespecified reporting and tail scenarios

Calibrate only on 2015–2019. For each type, retain the positive-value median and 90th percentile. Use the linear order-statistic quantile (Hyndman–Fan type 7) and round to the nearest cent, ties to even. Also retain the pooled positive-value 99th percentile as a common event-level tail cap. These are fixed sensitivity conventions, not optimized estimates of missing values, empirically tuned cutoffs or claims of plausible probabilities. Export every calibration value and the empirical sample counts.

Evaluate all three blank-value scenarios: assign zero; assign the type's calibrated positive median; assign its calibrated positive 90th percentile. Explicit reported zeros are never reclassified or imputed. Cross these with raw amounts and a cap at the calibrated pooled 99th percentile, applied to every event after scenario filling. This yields six declared accounting scenarios, with the uncapped blank-as-zero recorded-total comparator. Capping deliberately changes the estimand and is not a corrected estimate of true losses. Blank scenarios address only recorded blanks: unreported events, underestimates and zeros concealing unavailable estimates remain unidentified. Actual losses are not bounded by these scenarios.

Export each state's minimum/maximum point rank across the six scenarios, deterministic alphabetical tie-breaking and exact tie flags. Also export top-two membership, pairwise score contrasts, all annual scores and all leave-one-evaluation-year-out scores. Rank 1 is the largest share. No scenario is selected as the truth after seeing the result. Commit calibration thresholds, source accounting and analysis code before first 2020–2023 rank, damage-total or bootstrap output. Source coverage/format counts over the whole snapshot are allowed earlier; evaluation dollar summaries and ranks are reserved.

## Resampling comparison and independent checks

For each scenario report 1,000 within-year bootstrap replicates under two units: individual event reports (a naive independence comparator) and NWS episode blocks (primary dependence sensitivity). Resample a year's observed global units with replacement, preserving each sampled unit's full six-state vector and scenario values, then compute the mean of annual state shares. Episodes can contain reports from several states; preserve that vector rather than independently resampling each state. Year strata remain fixed. Episode identifiers do not eliminate all cross-office or cross-episode dependence. Exchangeability within a year is an assumption; seasonal/event-type mix, reporting selection and missing-not-at-random losses limit these conditional resampling summaries.

Use NumPy PCG64, base seed 20261029, separately seeded streams for each unit/year with seed=base+100*unit_index+year (event_index=0, episode_index=1). Process replicates in ascending order; each draws n unit indices uniformly in [0,n). Apply the same counts to all six scenarios for a paired comparison. Fix source row/event-code order for event units and (year,episode ID) numeric order for episode units. Retain every replicate/state/scenario score and rank, 2.5/97.5 percentiles, rank frequencies, top-two frequencies and interval widths. These are conditional empirical resampling summaries, not confidence about missing losses, future hazards or true geographical risk. Report Monte Carlo granularity 1/1000 and the maximum binomial Monte Carlo standard error of about 1.6 percentage points for frequencies. A zero-denominator replicate is retained as a failure/undefined result, not silently discarded.

Use integer cents for source amounts, filled values, caps, unit vectors and resampled sums; check integer-overflow bounds before multiplication. A separate standard-library/Decimal/SQL path must reconstruct damage-unit parsing, selected source fields, eligibility, calibration quantiles, all state/year/type totals, ranks, missingness and leave-year-out scores without importing primary helpers. Independently regenerate bootstrap indices using the documented PCG64 streams and reconstruct their weighted values through a different aggregation path; shared RNG-library use must be disclosed, not described as independent RNG certification. Independently recompute every retained bootstrap score/rank/interval/frequency and plotted/manuscript value. Scientific comparisons retain absolute 1e-7 / relative 1e-9 tolerances; source cents and discrete ranks must match exactly.

Meaningful boundary checks cover K/M/B/blank/explicit-zero parsing, malformed and negative amounts, type-7 quantiles and cent rounding, exact ties, heavy-tail capping, equal-year versus cumulative weighting, episode preservation across states and fixed-stratum resampling. No trained predictive model, hyperparameter optimization or train/test-loss claim is needed for this descriptive question. Calibration/evaluation separation protects scenario construction, not prospective forecasting or population generalization.
